# 债市与债券基金监测工具设计

日期：2026-08-25
状态：用户已审阅并批准，进入实施阶段

## 1. 目标

建立一个轻量、本地运行的债市监测工具，每个交易日自动采集中国国债、国开债、银行二级资本债、银行永续债和回购资金价格，保存 2020 年至今的历史数据，计算信用利差与变化 BP，并依据当时已经公开的定期报告，为以下三只基金生成透明、可追溯的市场压力代理：

- 兴全恒裕债券 A（006985）
- 长盛安逸纯债 A（007744）
- 广发添财 180 天滚动持有债券 A（012591）

工具不预测基金当日净值，不把季报持仓视为实时持仓。所有基金判断必须标明报告日期、发布日期、数据来源和可信度。

## 2. 成功标准

1. 首次运行可回填 2020 年至最近完整交易日的市场数据。
2. 每个交易日 17:40 自动更新；数据未发布时 18:10 重试。
3. 电脑关机或休眠后，下次启动能够补齐缺失交易日。
4. 单页展示市场概览、长期趋势、压力拆解和三只基金对比。
5. 每个压力值可以展开查看原始指标、公式、季报版本和来源。
6. 新季报发布后自动检查并更新基金画像；解析失败时保留上一份有效画像。
7. 官方源失败时使用明确标记的备用源；全部失败时留空，不用旧值冒充新值。
8. 同一天重复更新不产生重复记录。

## 3. 非目标

- 不提供交易下单、调仓建议或收益承诺。
- 不生成或恢复基金实时净值估算。
- 不接入 Wind 等付费终端或要求用户提供账号。
- 不做云同步、登录、多人权限、消息推送或 Mac 系统通知。
- 不修改 `/Users/didi/UX-Process-Map` 或其他既有项目。

## 4. 轻量架构

项目独立位于 `/Users/didi/bond-monitor`。

```text
macOS 定时任务（交易日 17:40）
                ↓
         Python 采集与校验
                ↓
            SQLite
                ↓
         导出前端所需 JSON
                ↓
      原生 HTML / CSS / JavaScript
```

不使用 React、Node、云端数据库或常驻复杂后台。Python 程序同时承担数据更新、历史补齐、季报画像更新和本地页面服务。页面服务只提供静态文件、状态读取和手动更新三个本机接口；不引入 Web 框架，也不监听局域网地址。依赖尽量使用标准库；网页和报告解析确有需要时，仅加入少量、固定版本的小型依赖。

运行方式保持两个命令：

```text
python3 app.py update   # 定时任务或手动命令更新数据
python3 app.py serve    # 在 127.0.0.1 启动页面和最小本地接口
```

页面“立即更新”按钮调用本机 `POST /refresh`，状态读取使用 `GET /status`，其余页面与数据均为静态文件。

## 5. 数据范围与口径

### 5.1 市场指标

每日保存：

- 国债到期收益率：1Y、3Y、5Y、10Y。
- 国开债到期收益率：1Y、3Y、5Y、10Y。
- 银行二级资本债行权收益率：AAA-/AAA，1Y、3Y、5Y。
- 银行无固定期限资本债行权收益率：AAA-/AAA，1Y、3Y、5Y。
- R007、DR007 及 R007-DR007 利差。

自动计算：

- 单日变化 BP。
- 5 个交易日变化 BP。
- 二级资本债相对同期限国开债的信用利差。
- 永续债相对同期限国开债的信用利差。
- 可选的永续债相对二级资本债利差，用于拆分更深次级风险。

换算规则：

```text
变化 BP =（今日收益率 - 对比日收益率）× 100
信用利差 BP =（二永债收益率 - 同期限国开债收益率）× 100
```

收益率数据库统一保存为百分比数值，例如 `1.68` 表示 `1.68%`，避免百分数与小数混用。

### 5.2 数据源策略

官方优先：

- 中国货币网：国债、国开债收盘或实时收益率曲线，R/DR 回购数据。
- 中债收益率曲线：2020 年以来连续的国债、国开债和银行资本债曲线。
- 上海清算所：2026 年 7 月以后发布的二级资本债、无固定期限资本债行权收益率曲线，用于近期交叉核对。
- 基金管理人官网、中国证监会基金电子披露网站或法定信息披露文件：季报、半年报、年报和基金净值。

备用源仅在官方源失败时启用，优先选择新华社中国金融信息网等可追溯来源。每条数据保存来源 URL、抓取时间和 `official/fallback` 状态。

为避免历史断点，二永债主历史序列维持同一中债曲线口径；上海清算所新曲线不直接拼接进旧序列，只作为并行校验序列保存。

### 5.3 历史区间

- 市场指标目标区间：2020-01-01 至最近完整交易日。
- 长盛安逸纯债画像从基金成立且报告可获得时开始。
- 广发添财 180 天画像从 2021-07-08 成立后且报告可获得时开始；成立前显示“不适用”。
- 缺少历史季报的区间保留市场数据，但基金压力显示“画像缺失”，不使用未来持仓倒推。

## 6. 基金画像

每一份公开定期报告形成一个版本化画像，字段包括：

- 基金代码、报告截止日、实际发布日期。
- 基金总资产、净资产、债券仓位、推算杠杆。
- 国债、政策性金融债、普通金融债、二级资本债、永续债、企业债、中期票据、同业存单等代理比例。
- 前五大债券代码、名称、类型、占净值比例。
- 短、中、长久期代理权重。
- 信息覆盖率和画像可信度。

历史压力计算只使用当日已经公开的最近一份报告。例如报告截止日为 3 月 31 日、发布日期为 4 月 22 日，则该画像从 4 月 22 日起生效，避免前视偏差。

新报告自动更新前必须通过：

1. 基金代码与份额类别校验。
2. 报告截止日与发布日期校验。
3. 资产总额、净资产、债券比例合理性校验。
4. 前五大债券条数和字段完整性校验。
5. 新旧画像异常跳变检查。

任一关键检查失败时，不替换上一份有效画像。

## 7. 压力代理模型

### 7.1 三类压力

```text
利率压力
= 国债、国开债不同期限收益率变化 × 基金期限与品种权重

信用压力
= 二级资本债、永续债信用利差变化 × 基金公开持仓暴露

融资压力
= R007、DR007 与 R-DR 利差变化 × 基金推算杠杆程度
```

评分同时参考单日和 5 日变化，输出 0-100 的压力值和绿/黄/红三级状态。首版对收益率、信用利差和回购利率统一使用以下透明换算：

```text
标准压力 = clamp(
  50 + 50 × [0.4 × 单日变化BP / 3 + 0.6 × 5日变化BP / 8],
  0,
  100
)
```

收益率或利差上升代表压力增加，下降代表压力减轻。各期限标准压力先按基金画像权重合成分项压力，再按基金的利率、信用和融资暴露合成综合压力。所有权重必须归一化为 1，并可在页面展开查看。

初始状态区间：

- 0-35：绿色，压力较低或正在缓解。
- 36-64：黄色，中性或需要关注。
- 65-100：红色，压力较高。

若缺失指标对应权重超过 20%，不输出综合压力；不超过 20% 时对剩余权重重新归一化，同时将可信度降低一级。评分规则必须是确定性的配置，而非不可解释的机器学习模型，后续调整阈值需要保留配置版本。

### 7.2 基金差异

- 兴全恒裕：优先使用银行二级资本债、5 年附近国开债、二级资本债信用利差和回购成本。
- 长盛安逸纯债：根据当期利率债、金融债、信用债和久期结构动态配置权重。
- 广发添财 180 天：优先使用 1-3 年国债/国开债、短信用债代理和资金价格；180 天表示份额滚动持有安排，不作为债券剩余期限。

压力值只描述公开持仓代理下的市场环境，不表示基金必然上涨或下跌。页面必须同时展示画像日期和可信度。

## 8. 单页界面

### 8.1 顶部

- 标题“债市监测”。
- 最近完整数据日期、更新时间、官方源可用状态。
- “立即更新”按钮。
- 当前筛选区间的 CSV 导出按钮。

### 8.2 市场概览

首页重点卡片显示国债 10Y、国开债 5Y、二级资本债 5Y、二级资本债信用利差和 R007；每张卡同时显示当日变化 BP。其他期限在展开区和趋势图选择器中提供。

### 8.3 趋势图

- 时间范围：1 月、3 月、1 年、2020 至今、自定义。
- 可切换国债、国开债、二级资本债、永续债、信用利差和回购利率。
- 不同数据源的序列不隐藏拼接。
- 工具提示显示日期、原始值、变化 BP、来源和质量状态。

### 8.4 今日压力拆解

分别显示利率、信用、融资和数据质量状态，并用一句话解释触发原因。

### 8.5 三只基金对比

三张基金卡并排展示：

- 综合状态。
- 利率、信用、融资三个分项压力。
- 季报截止日、发布日期和可信度。
- 点击后在当前页面展开权重、指标变化和计算过程，不跳转多层页面。

### 8.6 视觉原则

- 单页、桌面优先并适配手机纵向布局。
- 中性浅色背景，绿色表示压力下降、黄色表示关注、红色表示压力上升。
- 颜色之外同时提供文字和图标，避免只靠颜色传达状态。
- 不使用夸张金融行情样式，不制造实时交易错觉。

## 9. 更新与容错

### 9.1 调度

- macOS 定时任务在交易日 17:40 运行。
- 关键官方数据尚未发布时 18:10 重试。
- 启动工具时自动发现并补齐缺失交易日。
- 手动更新与定时更新使用同一幂等流程。

### 9.2 缺失处理

- 周末和法定休市日不算缺失。
- 官方失败、备用成功：使用备用值并明确标记。
- 全部失败：指标留空，禁止前值填充后伪装成当日值。
- 缺少关键指标：不生成完整压力分数，显示“数据不足”或降低可信度。
- 季报解析失败：沿用上一份有效画像并显示“画像已过期”。

### 9.3 可追溯性

标准化记录保留：指标名、期限、评级、日期、数值、单位、来源、来源等级、抓取时间和校验状态。官方修订值可以替换标准展示值，但必须保存修订记录。

## 10. 数据存储

SQLite 至少包含以下逻辑实体：

- `market_observations`：每日标准化市场指标。
- `source_fetches`：每次抓取结果和错误摘要。
- `fund_reports`：定期报告元数据和本地解析状态。
- `fund_profiles`：版本化基金画像。
- `fund_pressure`：按日期、基金、画像版本生成的透明压力结果。
- `revisions`：数据修订前后值与原因。

数据库负责唯一性约束和历史追溯；前端读取为展示生成的精简 JSON。唯一的写操作是本机手动更新接口，避免运行复杂 API 服务。

## 11. 验证

### 11.1 数据与公式

- 2020 至今每个指标的交易日覆盖率检查。
- 收益率单位和 BP 换算单元测试。
- 信用利差与 R-DR 利差固定样例测试。
- 同日重复抓取幂等测试。
- 官方、备用和全失败三种分支测试。
- 来源切换与曲线断点检查。

### 11.2 报告与画像

- 三只基金各准备至少一份固定报告样例。
- 验证基金代码、日期、债券比例和前五大持仓解析。
- 验证画像只在报告发布日期后生效。
- 验证解析失败不会覆盖有效画像。

### 11.3 页面

- 验证 2020 至今和短期时间范围切换。
- 验证三只基金展开后的计算来源一致。
- 验证缺失、备用源和过期画像提示。
- 验证桌面和手机宽度下的可读性、键盘操作和色彩对比。

## 12. 安全与说明

- 只读取公开市场和公开基金披露数据。
- 不采集用户账户、持仓金额或交易信息。
- 页面固定说明：数据可能延迟；基金压力为公开季报代理，不代表实时持仓、实时净值或投资建议。

## 13. 交付边界

首版交付包含：本地项目、2020 至今历史回填、每日自动更新、单页面板、三基金代理模型、来源追踪、CSV 导出和安装/使用说明。首版不包含云端部署、通知、复杂策略回测和更多基金扩展界面。
