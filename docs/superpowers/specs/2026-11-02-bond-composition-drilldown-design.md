# 债券构成饼图与持仓下钻设计

## 目标

让用户先看清单只基金内部各类债券的准确比例，并能通过悬停或聚焦快速查看该类别对应的公开持仓信息。

## 已确认方案

- 采用最终确认稿：左侧三张分类卡片，右侧环形饼图，下方为当前类别明细。
- 饼图只表示债券资产内部构成，三个类别合计 100%。
- 总债券仓位独立显示，例如 110.86%，避免与内部构成混淆。
- 信用债、利率债、其他债券卡片和饼图扇区均可切换类别，并同步更新下钻面板。
- 选中态采用方案 C：柔和阴影、轻微抬升和饼图扇区突出，不使用黑色整圈描边。

## 下钻内容

面板包含两层数据：

1. **完整品种汇总**：展示季报披露的该类别全部品种、占基金净值比例，以及该品种在当前类别内部的比例。
2. **已披露具体债券**：只展示季报前五大持仓中属于当前类别的具体债券名称、类型和占基金净值比例。

季报未披露全部逐只债券，因此面板明确使用“已披露具体债券”措辞，不将前五大持仓描述成全部持仓。

## 交互与状态

- 默认选中占比最大的类别，当前数据下通常为信用债。
- 桌面端鼠标移入分类卡片或饼图扇区时立即切换，不要求点击。
- 鼠标离开后保留最后查看的类别，不自动跳回默认类别。
- 触屏端轻触分类卡片切换；键盘聚焦分类卡片时同步切换。
- 当前分类卡片使用该分类色的柔和阴影与轻微位移，饼图对应扇区同步放大并增加同色光晕。
- 分类卡片不使用黑色整圈描边；左侧分类色条始终保留，用于建立卡片与扇区的映射。
- 下钻面板标题、品种汇总和具体债券列表同步更新。
- 当前类别没有进入前五大的具体债券时，显示“前五大持仓中暂无该类别债券”，不显示空白。
- 所有分类卡片保留可识别的键盘焦点状态；饼图保留清晰的辅助说明。

## 响应式布局

- 桌面端：三张分类卡片在左侧纵向排列，环形饼图在右侧，下钻面板横跨其下。
- 窄屏：三张分类卡片改为饼图上方的三列按钮；饼图和下钻面板保持单列。

## 验证

- 三只基金默认都能显示信用债下钻。
- hover 利率债后，品种和前五大债券只显示利率债数据，并在鼠标移开后保持该状态。
- 触屏轻触和键盘聚焦可以完成与 hover 相同的切换。
- 内部比例之和约为 100%，占基金净值比例保持原始季报口径。
- 现有数据加载、展开完整季报数据、移动端布局和测试不回归。
