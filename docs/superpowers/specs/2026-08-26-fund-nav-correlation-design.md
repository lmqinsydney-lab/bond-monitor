# 基金净值与债市指标同日对照设计

日期：2026-08-26  
状态：交互方案 A 已获用户确认，等待书面规格复核

## 1. 目标

在现有本地债市监测页面中增加“净值同日对照”区域，让用户能够：

1. 在兴全恒裕债券 A（006985）、长盛安逸纯债 A（007744）和广发添财 180 天滚动持有债券 A（012591）之间切换。
2. 选择任一有基金净值的交易日，并排查看该日单位净值、日收益率和与该基金相关的债市指标。
3. 使用前一交易日、后一交易日、日期选择器或图表点击灵活切换日期。
4. 在 20、60、120 个共同交易日、近 1 年和全部历史范围之间切换。
5. 查看基金日收益率与各指标单日 BP 变化的样本内 Pearson 相关系数、方向、强弱和样本量。

该功能用于验证公开代理指标与基金历史净值之间是否存在稳定的同向或反向关系，不提供净值预测、因果结论或交易建议。

## 2. 核心判断口径

### 2.1 不对长期水平序列直接计算相关性

不得直接使用“单位净值水平 vs 收益率水平”计算相关系数。两个长期水平序列可能因为共同趋势得到虚假的高相关。

相关性统一使用：

```text
基金变量 = 基金当日收益率（发布的日增长率，单位 %）
指标变量 = 指标相对前一有效交易日的变化（单位 BP）
相关系数 = Pearson(日收益率, 指标单日变化 BP)
```

债券收益率、信用利差和 DR007 上升通常增加基金压力，因此原始相关系数通常预期为负。页面不把负相关改写成正相关，而是解释为“指标上升时基金更容易下跌”。

### 2.2 相关强弱

按相关系数绝对值 `|r|` 标记样本内强弱：

- `< 0.20`：很弱
- `0.20–0.39`：较弱
- `0.40–0.59`：中等
- `0.60–0.79`：较强
- `>= 0.80`：很强

规则同时展示正负号、自然语言方向和样本数。例如：

```text
r = -0.63 · 较强负相关 · 60 个共同交易日
指标上升时，基金日收益通常更弱；仅代表样本内同步关系。
```

共同样本少于 20 个交易日时，不输出相关等级，只显示“样本不足”。相关性不解释为因果关系。

## 3. 基金与指标映射

页面只展示所选基金的公开画像相关指标，避免让用户自己从全市场指标中猜测。

### 兴全恒裕债券 A（006985）

- 国开债 5Y、10Y 收益率变化。
- 二级资本债相对国开债 3Y、5Y 利差变化。
- DR007 变化。

### 长盛安逸纯债 A（007744）

- 国开债 5Y、10Y 收益率变化。
- AAA 中票相对国开债 3Y 利差变化。
- 二级资本债相对国开债 5Y 利差变化。
- 银行永续债相对国开债 5Y 利差变化；数据缺失时明确显示为空。
- DR007 变化。

### 广发添财 180 天滚动持有债券 A（012591）

- 国开债 1Y、3Y 收益率变化。
- AAA 中票相对国开债 1Y、3Y 利差变化。
- DR007 变化。

映射沿用版本化基金画像；画像更新后，后续日期使用新画像。首版相关性图使用当前公开画像筛选指标，并在界面标注画像截止日，避免伪装成历史持仓精确回测。

## 4. 净值数据

### 4.1 字段

新增独立的 `fund_nav_observations` 表：

- `fund_code`
- `nav_date`
- `unit_nav`
- `cumulative_nav`
- `daily_return_pct`
- `source`
- `source_url`
- `source_tier`（`official` 或 `fallback`）
- `fetched_at`
- `quality`

对基金代码、净值日期和来源建立唯一约束；同值重复抓取不新增记录。另建 `fund_nav_revisions` 保存净值、累计净值或日增长率的旧值、新值、修订时间和原因；不复用只关联 `market_observations` 的现有 `revisions` 表。

### 4.2 收益率与分红

优先保存来源发布的“日增长率”，不使用单位净值简单相减推导收益率，因为分红除权可能造成单位净值机械下降。来源未提供日增长率时保留为空，不用可能失真的结果补齐。

### 4.3 来源策略

基金管理人或法定披露渠道提供稳定的机器可读历史净值时使用官方源；首版无法稳定自动读取官方历史序列时，使用东方财富历史净值接口作为明确标记的备用源。备用源不会显示成基金公司官方数据。

目标历史范围：

- 006985：2020-01-01 至最新可用净值日。
- 007744：2020-01-01 至最新可用净值日。
- 012591：2021-07-08 成立日至最新可用净值日。

每日更新复用现有更新命令。现有 17:40、18:10 更新继续采集债市数据，并增加 21:30 净值补偿更新，避免基金净值尚未发布导致长期滞后；登录补缺和手动更新仍会检查全部数据。

## 5. 日期对齐

以基金净值交易日为主轴，只在指标具有同一自然日数据时形成共同样本：

- 不使用前值填充。
- 不把周末、节假日或缺失日期补成零变化。
- 同日无指标值时，当日卡片显示“该指标尚未发布”，该日不计入该指标的相关性样本。
- 净值与市场数据发布日期不一致时，显示各自来源和日期。

日期选择器仅提供存在基金净值的日期。前后按钮跳到基金的前一或后一有效净值日，而不是简单加减一个自然日。

### 6.1 控件

- 基金选择器默认兴全恒裕 A。
- 时间范围默认 60 个共同交易日。
- 日期默认所选基金最新可用净值日。
- 日期输入、前后按钮和图表点击共享同一个选中日期状态。
- 切换基金后自动切到该基金最新净值日，并替换指标集合。

### 6.2 当日对照卡

第一张为基金净值卡，显示单位净值、日增长率和净值来源。后续卡片依次显示相关指标原始值、单日 BP、对基金的常见影响方向和来源日期。

颜色表达“对基金的常见压力方向”，同时必须使用文字：

- 指标上升：`压力增加`。
- 指标下降：`压力缓解`。
- 缺失或变化为零：`方向不明确`。

### 6.3 同步小图

使用原生 SVG 绘制上下排列的小图：

- 第一行绘制基金日收益率，以零轴为中心。
- 每个相关指标独占一行，绘制单日 BP 变化，以零轴为中心。
- 所有小图共用同一日期轴和竖向选中游标。
- 每行独立缩放纵轴，避免不同单位相互挤压；行标题始终显示单位。
- 悬停或点击任一位置时，所有行同时定位到同一交易日，并刷新上方当日卡片。
- 20、60、120 日使用柱形变化；1 年和全部范围使用折线或抽样后的 SVG 路径，避免生成数千个 DOM 柱。

### 6.4 相关性摘要

每个相关指标显示：

- Pearson `r`。
- 正/负方向。
- 强弱等级。
- 共同样本量。
- 是否符合“收益率或利差上升通常增加基金压力”的常见方向。

不提供“预测准确率”或“明日涨跌概率”。

## 7. 数据导出

页面 JSON 增加 `fund_nav_comparison`：

- 三只基金的净值序列。
- 每只基金的相关指标键。
- 按基金净值日期对齐的当日记录。
- 各预设范围的相关系数、样本量和强弱等级。
- 净值来源、最新日期和质量状态。

CSV 增加独立下载入口“导出同日对照”，按所选基金和时间范围输出：

```text
日期,基金代码,单位净值,日收益率,指标代码,指标值,指标单日变化BP,净值来源,指标来源
```

## 8. 容错与状态

- 净值源请求失败：保留历史数据，页面标记最近成功日期，不阻断债市数据更新。
- 单只基金失败：另外两只基金仍可使用。
- 某指标缺失：同日卡和小图该行显示缺口，其他行继续展示。
- 相关样本不足：不计算等级，不用零值替代。
- 来源修订：更新原值并记录修订，重新生成相关系数。

## 9. 测试与验收

### 数据测试

- 净值接口正常、分页、空响应、重复值、修订和字段变化。
- 分红日前后优先使用发布的日增长率。
- 2020 回填和基金成立日前边界。
- 净值源失败不影响市场源事务。

### 相关性测试

- 完全正相关得到 `+1`，完全负相关得到 `-1`。
- 常数序列、少于 20 个样本和缺失日期返回“不可计算”。
- 不同自然日不得错位配对。
- 各强弱阈值边界确定且可复现。

### 页面测试

- 三只基金切换后指标集合正确。
- 日期输入、前后按钮、图表点击保持同步。
- 20/60/120/1 年/全部切换正确。
- 桌面端和 390px 窄屏无横向页面溢出；图表区域可局部横向滚动。
- 键盘可以操作基金、日期、范围和图表日期选择。
- 浏览器无控制台错误。

最终验收标准：用户无需记忆基金与指标映射，即可选择任一基金和净值日，在同一区域看到当日净值、相关市场指标和指定历史区间的样本内相关关系；任何缺失、备用源或低样本情况都不会被包装成确定结论。
